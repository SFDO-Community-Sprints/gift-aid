  • Donor Benefit Value on Opportunity (Currency): the value of any benefit the donor received for a gift, so HMRC's donor-benefit limits can be checked before claiming.

Not confirmed

  • Gift Aid Coverage Period fields shown with their org labels match the object as built (Contact, Start Date, End Date, End Reason, Is Active?, Declaration Date, Source, Address Line 1, Address City, Address Post Code). Address Country, Status, Change Reason, Ineligibility Reason and Reason Detail are not on the object yet.
  • Gift Aid Claim and the new Opportunity and Contact fields carry design labels, not deployed API names. The two Number fields are shown as COUNT roll-ups of Coverage Period and Gift Aid Active as a formula (Number of Active above 0); field types are proposals.
  • Declaration details on Coverage Period are not edited once the period has claimed gifts.
  • Contact roll-ups Gift_Aid_Start_Date__c and Gift_Aid_End_Date__c depend on the retired object; the formulas Gift_Aid_Eligibility__c and Gift_Aid_Status__c need review.
  • Only fields relevant to the Gift Aid processes are shown; Contact and Opportunity carry many more.
